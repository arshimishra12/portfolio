
# 🚀 Arshi Mishra — Personal Portfolio

A modern, cinematic, and interactive personal portfolio website built entirely with **Vanilla HTML5, CSS3, and JavaScript**.

Designed with a **dark cyberpunk aesthetic**, editorial-inspired typography, and a game-inspired user interface, this portfolio showcases my projects, skills, and journey as a Computer Science student through immersive animations and smooth interactions.

> ⚡ Zero Frameworks • Zero Dependencies • Zero Build Tools • Fully Deployable on GitHub Pages

# 🚀 Getting Started

Clone the repository:

```bash

```

Navigate to the project directory:

```bash
cd portfolio
```

Open the project by simply launching:

```text
index.html
```

That's it!

No installation.

No dependencies.

No build process.

---

# 🌍 Deployment

Deploying this portfolio using GitHub Pages only takes a few minutes.

1. Push the project to your GitHub repository.
2. Open your repository.
3. Go to:

```
Settings
→ Pages
→ Build and deployment
```

4. Select:

```
Source:
Deploy from a branch
```

5. Choose:

```
Branch: main
Folder: / (root)
```

6. Click **Save**.

Your website will be available at:

```
https://your-username.github.io/repository-name/
```

# ✏️ Customization

## Personal Information

Edit the following sections inside:

```
index.html
```

- Hero
- About
- Education
- Contact

---

## Profile Image

Replace:

```
assets/images/arshi-portrait.jpg
```

with your own image while keeping the same filename.

---

## Projects

Project details are stored inside:

```
js/script.js
```

Update the `projectsData` object to edit:

- Project Title
- Description
- Technologies
- Images
- Project Links

---

## Social Links

Update the `href` attributes inside:

```
index.html
```

Replace them with your own:

- GitHub
- LinkedIn
- Email
- Instagram
- Resume

---

## Theme Colors

The complete color palette is defined inside:

```
css/style.css
```

You can customize:

- Background colors
- Accent colors
- Glow effects
- Typography
- Button styles

---

## Responsive Design

Device-specific layouts are located in:

```
